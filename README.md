# Task-4-Alaezi-Emmanuel - Ecommerce Dashboard 

**Tools**: Excel with PivotTables + Slicers + Charts
**Results**: 1,200 orders | $1.26M revenue | AOV $1,054

### Project Overview
Built an interactive Excel dashboard to analyze and track e-commerce sales performance across products, referral sources, payment methods, and monthly trends. All KPIs and charts update dynamically with slicer filters.

### Key Insights
**Top Channel**: Instagram $275K - best referral source.
**Top Products**: Printer $195K, Chair $195K.
**Seasonality**: May $170K peak vs Aug $68K low.
**Payment Mix**: 5 methods tracked - Cash, Card, Online, Gift Card.
